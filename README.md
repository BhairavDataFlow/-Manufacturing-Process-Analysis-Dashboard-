# Manufacturing Process Analysis Dashboard

## 📊 Overview

This project presents a Power BI dashboard to analyze manufacturing process performance and monitor production efficiency.

## 🔍 Key Insights

* Output is below target
* Efficiency is around 70%
* Process shows instability
* Temperature has minimal impact on output

## 🛠 Tools Used

* Power BI

## 📁 Files Included

* Power BI Dashboard (.pbix)
* Dashboard Screenshot

## 🎯 Objective

To monitor production performance, compare actual vs target output, and identify factors affecting the process.

## 📌 Conclusion

The process is underperforming and unstable, indicating the need for better control of production factors.
